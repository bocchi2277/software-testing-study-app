# مسار QA — الطريق إلى ISTQB 🧭

تطبيق أندرويد أصلي (**Android — Kotlin & Jetpack Compose**) باللغة العربية لدراسة **Software Testing / QA**، والتحضير لاجتياز شهادة **ISTQB Foundation Level (CTFL v4.0)**، والاستعداد العملي لسوق العمل.

> **سياسة اللغة:** الشرح والواجهة بالعربية (RTL)، أما **مصطلحات الاختبار** فتبقى بالإنجليزية كما تظهر في المنهج والامتحان (مثل `Defect` و`Failure` و`Test case` و`Static testing` و`Boundary Value Analysis`)، مع إتاحة **النسخة الإنجليزية الرسمية لصياغة الأسئلة والخيارات والتفسيرات** بضغطة واحدة أثناء التدريب والمحاكاة والمراجعة.

---

## المميزات والأقسام الرئيسية

* **الرئيسية:** لوحة متابعة يومية تضم العدّاد التنازلي لموعد الامتحان، مؤقت **Pomodoro** مستمر أثناء التنقل بين الشاشات مع تنبيه صوتي واهتزازي عند الاكتمال، نظام **XP ومستويات التركيز**، تسجيل جلسات الدراسة اليدوية، خطتك الذكية اليوم (الموضوع التالي، البطاقات المستحقة، أضعف فصل، ومراجعة الأخطاء)، رسم بياني لآخر 7 أيام، وقائمة مهام اليوم.
* **خارطة المنهج (Roadmap) ومنهج CTFL v4.0:** الفصول الستة كاملةً (**25 موضوعاً**) مع بحث فوري، وزر مباشر لدخول كل فصل (`دخول الفصل / متابعة ←`)، و**«زتونة الفصل»** (ملخص سريع بالقوانين والفروقات وفخاخ الامتحان)، والأهداف التعليمية (`K1 / K2 / K3`)، وملاحظات ومصادر عربية وإنجليزية مرتبطة بكل موضوع.
* **الاختبارات والمحاكاة (120 سؤالاً ثنائي اللغة AR/EN):**
  * بنك يضم **120 سؤالاً** متوافقة مع منهج **CTFL v4.0** موزعة على الفصول الستة (`20 / 16 / 14 / 38 / 22 / 10`) وتشمل أسئلة سيناريو وحسابات عملية (`K3`) وتغطي صيغ الامتحان الرسمية (`EN ⇄ عربي` داخل الجلسة وعند مراجعة الأخطاء).
  * **محاكاة الامتحان الرسمي:** 40 سؤالاً مسحوبة بالأوزان الرسمية للامتحان (`8 / 6 / 4 / 11 / 9 / 2`)، بخيار **60 دقيقة** أو **75 دقيقة** لغير الناطقين بالإنجليزية، مع تعليم الأسئلة للمراجعة وتفصيل النتيجة حسب كل فصل.
  * **حفظ حالة الجلسة:** الحفاظ على الإجابات، الأسئلة المعلّمة، السؤال الحالي، لغة العرض، والمؤقت الزمني عند تدوير الشاشة أو إعادة إنشاء النشاط (`rememberSaveable`).
* **بطاقات المصطلحات والقاموس:** **68 مصطلحاً** بنظام التكرار المتباعد (**Leitner** عبر 5 صناديق)، بالإضافة إلى قاموس ثنائي اللغة قابل للبحث والفلترة. المصطلح بالإنجليزية وتعريفه بالعربية.
* **المختبر التفاعلي:** 5 أدوات عملية لحسابات الامتحان (`K3`):
  1. مولّد **Equivalence Partitioning** و**BVA (2-value & 3-value)**.
  2. مولّد **Decision table** التفاعلي (`2^n`).
  3. محاكي **Statement vs Branch coverage**.
  4. حاسبة تقدير الجهد (**Three-point estimation**).
  5. حاسبة مستوى المخاطرة (**Likelihood × Impact**).
* **المهارات العملية:** 9 أقسام تطبيقية (**Test cases**، **Defect reports**، **Severity مقابل Priority**، **User Story وAcceptance criteria**، **Exploratory testing**، **Test plan**، **Test summary report**، مراجعة المتطلبات، والتواصل مع المطورين)، مع قوالب جاهزة للنسخ إلى الحافظة وأداة **مدقّق Defect report** التفاعلية التي تفحص اكتمال عناصر التقرير السبعة.
* **المصادر المجانية:** دليل منسّق يضم **131 مصدراً مجانياً** (عربي وإنجليزي) في 10 تصنيفات تشمل **مستودعات GitHub والملخصات والخرائط الذهنية**، مع بحث وفلترة حسب الفصل (`فصل 1..6` أو `عام للمنهج`) واللغة والمستوى وحفظ التقدّم، وتقديم المصادر العربية والملخصات في كل فصل مع عزل المصادر العامة، بالإضافة إلى أزرار انتقال مباشر من المواضيع إلى المختبر التفاعلي وأقسام المهارات العملية.
* **دليل الشهادة:** فاحص الجاهزية للحجز، حقائق الامتحان، جدول الأوزان، خطوات الحجز (بما في ذلك بوابة **ESTB / SECC** في مصر)، ونصائح يوم الامتحان.
* **المسار المهني:** خارطة طريق من 6 مراحل بعد الشهادة، أفكار محفظة أعمال (`Portfolio`)، **15 سؤال مقابلة عمل** بإجاباتها، نصائح CV بنظام ATS، وشهادات ISTQB التالية.
* **الخطة والجدول، الملاحظات، التقدم والإنجازات، والإعدادات:** جدول يومي ديناميكي، خطة 8 أسابيع، دفتر ملاحظات مرتبط بالمنهج، خريطة نشاط حرارية لـ 12 أسبوعاً، 10 شارات إنجاز، المظهر التلقائي/الفاتح/الداكن، مع **تصدير واستيراد النسخ الاحتياطية JSON** عبر نظام الملفات.

## التقنيات المستخدمة والاختبارات

* **اللغة والواجهة:** Kotlin + Jetpack Compose + Material Design 3 + Navigation Compose (Type-safe `@Serializable` routes) + WindowSizeClass (تخطيط متجاوب مع شاشات الهواتف والأجهزة اللوحية).
* **الحساب والمزامنة السحابية:** Firebase Authentication (تسجيل الدخول بحساب Google عبر Jetpack Credential Manager) وCloud Firestore لحفظ ومزامنة التقدم والبطاقات والاختبارات والملاحظات عبر الحساب الشخصي، مع دعم العمل محلياً وتصدير/استيراد النسخ الاحتياطية JSON.
* **اختبارات الوحدة (JVM Unit Tests):** تغطي خوارزمية Leitner، أوزان الجاهزية والامتحان الرسمي، نزاهة بنك الأسئلة (توازن طول الخيارات في الحدين الأعلى والأدنى بالعربية والإنجليزية ومنع الصيغ المعتمدة على الترتيب)، حفظ حالة الجلسة والمؤقت، وعزل مصادر الفصول والمواضيع وصحة بياناتها عبر `gradle :app:testDebugUnitTest`.
* **الخطوط والأصول:** IBM Plex Sans Arabic وJetBrains Mono مع أيقونة تكيفية مخصصة (`Adaptive Launcher Icon`).

## البناء محلياً بعد الاستنساخ من GitHub

* المتطلبات: Android Studio / JDK 17+ مع Android SDK (`compileSdk 36`, `minSdk 26`).
* ملف `app/google-services.json` غير مضمَّن في المستودع العام حفاظاً على إعدادات مشروع Firebase؛ لذا عند استنساخ المشروع خارج بيئة التطوير السحابية يجب ربطه بمشروع Firebase الخاص بك (تفعيل **Google Sign-In** في Authentication و**Cloud Firestore**) ووضع `google-services.json` داخل مجلد `app/` قبل تشغيل البناء أو الاختبارات (`gradle :app:testDebugUnitTest`).
